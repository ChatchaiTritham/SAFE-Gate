# Reproducibility

Every number in the IJFS manuscript (release tag `v2.0.0-ijfs`) is regenerated by

```bash
pip install -r requirements.lock      # exact versions, Python 3.11.15
pip install -e .
python run_all.py --round4            # about 1.5-2 h on a laptop CPU
python evaluation/generate_manuscript_figures.py
python scripts/check_manuscript_numbers.py path/to/sn-article.tex   # 0 mismatches expected
```

`python run_all.py` alone (a few minutes) regenerates the development-cohort
results; `--round4` adds the round-4 analyses in `scripts/round4.py`
(`--skip-multiseed` omits the 20-seed study). All randomness is seeded, and two
consecutive runs produce byte-identical files in `results/`.

Seeds and SHA-256 digests of the fresh and selection cohorts were committed in
`results/round4_protocol.json` (commit `03b0adb`) after all round-4 code was
committed (`7d09838`) and before any of them was scored; `scripts/round4.py
evaluate` regenerates each cohort and aborts if a digest differs.

## Calibration history (honest statement)

Calibration v1 was scored on the development test split in earlier rounds; the
five switches defining v2 were designed after its test failures were seen. v2
was then chosen among 128 profiles on the training split
(`scripts/select_calibration.py`, `results/calibration_protocol.json`). The
development test split is therefore development data. `results/round4_profiles.csv`
scores all 128 profiles on every cohort; a robustness-aware criterion selects a
different profile (v2 without the G5 escalation cap), reported as a second
operating point.

## What the invariants mean

CP, AC and CND are merge-level properties: they hold for ACWCM given the gate
outputs, for every input. They are not clinical safety. Critical sensitivity of
the whole system equals the share of critical cases for which at least one gate
fires (89.7% on the diagnosis-conditioned cohort).
